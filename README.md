# やまナビ（yama-app）

Pixel 7 Pro で使う自分用の山登りアプリ。

## できること
- 国土地理院の地図に現在地を表示（ルート周辺の地図を保存すれば圏外でも表示）
- ルート作成：地図をタップして点を打つ／GPX読み込み／前回の記録から作成
- 道誘導：ルートから 30 m 以上離れると振動と通知（画面OFFでも動作）
- 目安時間：標準タイム ＝ 27.8×距離[km] ＋ 7.2×登り[100 m] ＋ 3.3×下り[100 m]（分）
  - 自分のペース（実際の経過時間 ÷ そこまでの標準タイム）で残り時間を補正
- 登頂スタンプ：山頂から半径 50 m 以内で自動で押される（地図を長押しで山頂を追加）

## インストール
1. このリポジトリの Releases を開く
2. 最新版の `yama-app.apk` をタップしてダウンロード
3. ダウンロードした APK を開いてインストール（初回は「この提供元を許可」をオン）

APK は main に push すると GitHub Actions が自動でビルドして Releases に置きます。

地図データ：国土地理院（地理院タイル、標高API）
